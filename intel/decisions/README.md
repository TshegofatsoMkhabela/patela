> **Classification:** ADR Directory Index  
> **Last Updated:** 2026-11-09  

---

## 1. Purpose

The `intel/decisions/` directory stores formal **Architecture Decision Records (ADRs)** for the Patela platform. Whenever a significant technical choice is made—such as selecting a blockchain network, smart contract pattern, database schema design, authentication protocol, or AI verification boundary—a numbered ADR must be created using [ADR_TEMPLATE.md](./ADR_TEMPLATE.md) and linked in [../history/ARCHITECTURE_DECISIONS.md](../history/ARCHITECTURE_DECISIONS.md).
